# Полка — EPUB / FB2 Reader

Личная библиотека в браузере. Статическое приложение без серверной базы данных и без сборки.

## Первая версия

- EPUB, FB2, FB2.ZIP и FBZ; выбор нескольких файлов, перетаскивание, проверка дубликатов по SHA-256.
- Полка с обложками, авторами, поиском, прогрессом и кнопкой продолжения чтения.
- Иллюстрации, оглавление, переходы по сноскам. После перехода по ссылке вернуться можно через **Оглавление → Вернуться к тексту**.
- Одна колонка, страницы или прокрутка, размер и семейство шрифта, три темы.
- Перелистывание кнопками, стрелками клавиатуры, Page Up / Page Down, пробелом и горизонтальными свайпами.
- Автоматическая запись CFI (адреса фрагмента текста), а не номера страницы. Размер шрифта и размер экрана могут меняться.
- ZIP-копия исходных файлов и позиций; восстановление добавляет книги и сохраняет более свежую позицию.
- Офлайн-режим после успешного кеширования оболочки. Можно установить как веб-приложение через меню браузера, если браузер поддерживает установку.
- Собственная демонстрационная книга с иллюстрацией и сноской.
- Встроенное меню **Помощь** на полке и кнопка **?** во время чтения: добавление книг, инструкции для iPhone/iPad и Android, сохранение места, локальное хранение, резервные копии и офлайн-режим. Справка доступна вместе с офлайн-оболочкой.

## Где находятся книги

Файлы находятся в IndexedDB конкретного браузера и конкретного адреса сайта. Другие посетители сайта их не видят. Последняя позиция дополнительно записывается в синхронный журнал localStorage на случай закрытия вкладки до завершения транзакции IndexedDB.

Данные на адресах `workers.dev`, `github.io`, в обычном браузере и во встроенном браузере Telegram — **разные библиотеки**. Автоматической синхронизации между ними пока нет. Для переноса используйте **Сохранить копию → Восстановить**. Очистка данных сайта или удаление браузера может удалить локальные книги; сохраняйте резервные копии.

Лимит файла книги — 64 МиБ; распакованной книги — 256 МиБ. Общий доступный объём зависит от браузера. ZIP-копия создаётся в памяти; автоматический экспорт ограничен 240 МиБ исходных файлов, восстановление — 256 МиБ архива. Для большей библиотеки можно скачивать оригиналы по отдельности.

## Запуск и публикация

Приложение расположено в `book-reader/` и добавлено в корневой каталог приложений. Оно обслуживается существующими статическими assets Cloudflare Worker; менять `worker-src/`, секреты и настройки других приложений не нужно.

Основной адрес после публикации репозитория:

<https://miniapps.lechat-reg.workers.dev/book-reader/>

Резервный адрес при включённом GitHub Pages:

<https://l3chat.github.io/miniApps/book-reader/>

Для локальной проверки нужен HTTP-сервер, например `python -m http.server 8080` из корня репозитория. Откройте `http://localhost:8080/book-reader/`. Открытие HTML напрямую как `file://` не поддерживается. На внешнем адресе необходим HTTPS.

При изменении кода обновляйте `CACHE` и список файлов в `sw.js`. Новая версия service worker активируется после закрытия всех вкладок со старой версией. Кеш принадлежит только `book-reader/`; книги и позиции при обновлении оболочки сохраняются.

## Telegram

Подключён официальный Telegram WebApp SDK (локальная копия). В Telegram приложение вызывает `ready()` / `expand()`, учитывает высоту окна и безопасные отступы, использует кнопку Telegram «Назад» для возврата в библиотеку и сохраняет позицию при событии сворачивания. Во время чтения жест сворачивания содержимого отключается, чтобы не мешать прокрутке книги; на полке он снова включён. В обычном браузере эти функции не активируются.

Чтобы подключить приложение к боту:

1. Откройте [@BotFather](https://t.me/BotFather). Можно использовать существующего бота или создать отдельного командой `/newbot` (например, с названием «Полка — читалка книг»; свободное имя пользователя выбирается при создании).
2. Отправьте `/setmenubutton` и выберите нужного бота.
3. Укажите URL `https://miniapps.lechat-reg.workers.dev/book-reader/` и подпись кнопки `Читать` — в том порядке, в котором их запрашивает BotFather.
4. Откройте чат своего бота и нажмите **Читать**. В читалке выберите **Добавить книги** или демонстрационную книгу.

Для запуска прямо из профиля дополнительно настройте **Main Mini App**: `/mybots` → нужный бот → **Bot Settings → Configure Mini App**. После включения основного приложения и указания того же URL Telegram создаёт кнопку запуска в профиле и поддерживает ссылку `https://t.me/ИМЯ_БОТА?startapp`.

Для настройки через BotFather токен не нужен. Токен нельзя добавлять в браузерный код или публичный репозиторий. Приложение не регистрирует бота автоматически и не меняет меню существующих ботов. Оно также не отправляет запрос на разрешение писать пользователю.

Официальное описание настройки меню: <https://core.telegram.org/bots/webapps#launching-mini-apps-from-the-menu-button>.

Книги выбираются из интерфейса приложения. Приём файлов обычными сообщениями боту, серверное хранение, Telegram-идентификация и синхронизация пока не реализованы. Доступность выбора и скачивания файлов зависит от Telegram-клиента; наиболее надёжно пока использовать обычный браузер.

## Движок и лицензии

Используется [foliate-js](https://github.com/johnfactotum/foliate-js), MIT, commit `78914aef4466eb960965702401634c2cb348e9b1` (2026-05-01). Нужные модули сохранены в `vendor/foliate/`, включая его ZIP- и DEFLATE-зависимости. Файлы движка не изменены. Модули PDF, комиксов, TTS и интерфейс демонстрационного reader upstream не включены.

Для резервных архивов добавлен [fflate](https://github.com/101arrowz/fflate) 0.8.3, MIT. Лицензии: `vendor/foliate/LICENSE`, `vendor/zip-LICENSE`, `vendor/fflate-LICENSE`. Во время чтения загрузок библиотек со сторонних CDN нет.

EPUB может содержать исполняемый код. Поэтому `index.html` задаёт CSP без inline-скриптов, `eval` и внешних сетевых ресурсов; HTML/SVG разделов дополнительно очищается от скриптов, обработчиков событий, форм и перенаправлений. `script-src` нельзя расширять до `blob:` или `'unsafe-inline'`. Книги с DRM не поддерживаются. Сложная вёрстка, MathML и нестандартные EPUB требуют проверки на конкретном устройстве.

## Проверки

```sh
npm ci --prefix book-reader
npm test --prefix book-reader
```

Проверяются настоящие парсеры EPUB/FB2, картинки, оглавление, сноски, восстановление CFI на новом DOM, бинарное хранение IndexedDB, журнал позиции, дубликаты и ZIP-копии. DOM-интеграция проверяет загрузку, открытие сохранённой позиции и возврат на полку; пагинация в этом тесте заменена заглушкой. Визуальная проверка браузерного движка и Telegram остаётся отдельной проверкой.

Ручной сценарий: открыть пример → перейти на несколько страниц → закрыть книгу → закрыть вкладку → открыть снова → продолжить → изменить размер шрифта → повторить. Затем проверить EPUB и FB2 с иллюстрациями, экспорт/восстановление и открытие после отключения сети.
