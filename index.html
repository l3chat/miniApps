Mini Apps

A small collection of browser-based tools.

  • Fourier Epicycles Lab Draw a path and reconstruct it using signed Fourier harmonics and rotating epicycles.
  • Полка · EPUB & FB2 Reader A personal, offline book library with illustrations, a table of contents and automatic reading-position saving.
  • Markdown → Rich Message Turn Markdown, long text, tables, formulas and media into polished Telegram Rich Messages.
  • Schulte Table Responsive Schulte table timer with standard and center-dot variants.
  • Root Trainer Root Trainer
  • Календарь в уме · Calendar Trainer Find the weekday of a date using Conway’s Doomsday method.
  • RPN Calculator Six-level reverse Polish notation calculator with arithmetic, reciprocal, powers and roots.
  • RPN 3D Demo Playful Three.js demonstration of stack mechanics and reverse Polish notation with a robot and calculator.
  • Particle Cylinder Orthographic Three.js animation of a rigidly rotating particle cylinder.
  • Particle Crown Three.js animation of a rotating particle crown with a glowing torus and colored vertical streams.
